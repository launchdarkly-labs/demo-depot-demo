Demo Depot starter

One flag. One listener. Zero reloads.

This page evaluates a single LaunchDarkly flag in the browser and subscribes to changes. Flip promo-banner in LaunchDarkly and the banner above appears or disappears the moment the change streams in.

Fresh project per launch

Every launch from Demo Depot gets its own LaunchDarkly project, seeded from ld/seed.json.

Config at runtime

The browser fetches its client-side ID from /api/config. Nothing is baked into the image.

Live updates

client.on("change:promo-banner", …) re-renders the banner. No polling, no refresh.
